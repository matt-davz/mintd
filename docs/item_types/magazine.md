# Item Type: Magazine

Notable baseball magazines — signed issues, historically significant covers, first appearances, etc.

## Magazine-Specific Fields

| Field | Type | Notes |
|---|---|---|
| `publication_name` | text | e.g. "Sports Illustrated", "The Sporting News", "Life", "Sport", "Baseball Digest" |
| `issue_date` | date | Cover date of the issue |
| `volume` | text | Volume number if applicable |
| `issue_number` | text | Issue number within the volume |
| `publisher` | text | Publishing house |
| `cover_subject` | text | Who or what is featured on the cover |
| `is_cover_signed` | boolean | True if signed on the cover page specifically |
