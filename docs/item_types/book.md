# Item Type: Book

Signed books, autobiographies, yearbooks, and baseball reference publications.

## Book-Specific Fields

| Field | Type | Notes |
|---|---|---|
| `author` | text | Author(s) of the book |
| `publisher` | text | Publishing house |
| `year_published` | integer | Year of publication |
| `edition` | text | e.g. "1st Edition", "Limited Edition", "Revised" |
| `isbn` | text | ISBN if available |
| `is_first_edition` | boolean | True if confirmed first edition |
| `is_signed_by_author` | boolean | True if signed by the author (distinct from a subject signing) |
